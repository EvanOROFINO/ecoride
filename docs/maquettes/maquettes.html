Maquettes & Wireframes — EcoRide

Ce document présente les wireframes (basse fidélité) des 3 vues principales d'EcoRide, chacune déclinée en version desktop et mobile. La version haute fidélité (mockup) est l'application réelle accessible à http://localhost:8000.

Légende : [ ] = champ de formulaire · ( ) = bouton · < > = élément cliquable · {{ }} = donnée dynamique

Note méthodologique

Ces wireframes sont la version basse fidélité (structure et hiérarchie de l'information). La version haute fidélité (mockup) est implémentée directement dans le code et accessible à http://localhost:8000. La charte graphique appliquée est documentée dans docs/charte/charte_graphique.md : palette de verts (écologie), polices Poppins (titres) + Inter (corps), composants Bootstrap Icons.
