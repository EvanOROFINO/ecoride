4. POUR LANCER L'APPLICATION EN LOCAL
--------------------------------------

Prerequis : XAMPP (PHP 8.2, MySQL), Composer, MongoDB Server

1. Cloner le depot :
   git clone https://github.com/EvanOROFINO/ecoride.git
   cd ecoride

2. Configurer l'environnement :
   cp .env.example .env
   (editer .env avec vos identifiants)

3. Installer les dependances :
   composer install

4. Importer la base MySQL :
   mysql -u root < sql/01_schema.sql
   mysql -u root < sql/02_seed.sql

5. Initialiser MongoDB :
   php sql/init_mongo.php

6. Lancer le serveur :
   php -S localhost:8000 -t public

7. Ouvrir http://localhost:8000
